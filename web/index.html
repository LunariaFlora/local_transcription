            设置

            YouTube 导入方式

            推荐路线：Chrome 扩展导入列表

            打开 YouTube 的稍后观看、播放列表或搜索结果页，页面右侧会出现“导入工作台”按钮。点击后扩展会收集当前页面可见的视频链接，发送到本地工作台，并让 Edge 打开 YouTube 页。

            Codex 路线：让 Codex 自动抓取

            Codex 打开时，可以让 Codex 操控 Chrome 收集链接，再推送到同一个本地接口。这个路线适合你已经在 Codex 线程里继续自动化，不需要额外导出 cookies。

            兜底路线：复制粘贴或 cookies.txt

            公开视频直接复制多个链接到文本框后点“解析链接”。私有列表如果要用 yt-dlp 直接扫描，仍可能需要上传 YouTube cookies.txt，因为 Chrome 的加密 cookies 不一定能被 yt-dlp 解开。
